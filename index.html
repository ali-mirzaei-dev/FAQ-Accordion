var is function-scoped and legacy. let is block-scoped and reassignable. const is block-scoped and cannot be reassigned. Always use const unless you need to reassign the value later.
Hoisting is JavaScript's default behavior of moving variable and function declarations to the top of their current scope before code execution.
Template literals are strings defined with backticks (`) that allow for multi-line strings and string interpolation (embedding variables directly using ${variable}).
== checks for equality after performing type coercion (e.g., 5 == "5" is true). === checks for strict equality without type coercion (e.g., 5 === "5" is false). Always use ===.
Primitives are basic data types that are not objects and have no methods. JavaScript has 7: String, Number, Boolean, Null, Undefined, Symbol, and BigInt.
The Document Object Model (DOM) is a programming interface for HTML documents. It represents the page so that programs can change the document structure, style, and content.
getElementById is faster but strictly looks for an element by its ID. querySelector uses CSS selectors (like classes, tags, or IDs) and returns the first matching element.
Event bubbling means that when an event happens on an element, it first runs the handlers on it, then on its parent, then all the way up on other ancestors.
You use the event.preventDefault() method inside your event listener to stop the default action (like stopping a form from refreshing the page).
innerHTML parses the string as HTML and can execute scripts (security risk). textContent treats everything as plain text and is much safer and faster for reading or writing text.
An arrow function (() => {}) is a modern, shorter syntax for writing JavaScript functions. It does not bind its own `this` keyword, which solves many scope-related bugs.
A callback is a function passed as an argument to another function, which is then invoked inside the outer function to complete some kind of routine or action.
The return statement ends the execution of a function and returns a value from that function back to the place where it was called.
Default parameters allow named function parameters to be initialized with default values if no value or undefined is passed into the function.
An IIFE is a function that runs as soon as it is defined. It is wrapped in parentheses to create a function expression, and followed by () to execute it immediately.
forEach executes a function for each array element but returns undefined. map creates a brand new array with the results of the function applied to each element.
A Promise is an object representing the eventual completion or failure of an asynchronous operation. It allows you to write handlers that wait for a result without freezing the whole program.
Destructuring is a syntax that allows you to unpack values from arrays, or properties from objects, into distinct variables very quickly (e.g., const { name } = user;).
The spread operator (...) allows an iterable like an array or string to be expanded in places where zero or more arguments or elements are expected.
LocalStorage allows you to save key-value pairs in the browser so that data persists even when the page is refreshed or the browser is closed. It has no expiration date.
